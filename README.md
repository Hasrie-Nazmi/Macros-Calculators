# Macros Calculators
## Assorted fitness calculators project for practicing with Python CustomTkinter
## This game was developed using Python and CustomTkinter

## Features include:
* Calculate recommended daily macro intake based on: height, weight, age, gender, and activity level
* Simple unit conversion from kg to lbs and cm to feet and inches
* Simple calculator to manually calculate your total calories and other macros consumed
